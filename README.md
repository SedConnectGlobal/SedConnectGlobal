# SED Connect Global — Platform Defense Summary

Brief summary:

- The "PLATFORM DEFENSE" proposal outlines a centralized "SED One-Stop Shop" website to consolidate academic resources, announcements, CHED memos, student services, and internationalization opportunities.
- Built with Google Sites, it links to existing systems (LMS, student portal, EduDrive) and uses a governance team (one chief web manager, two content managers, and technical support) with controlled editing and monthly backups.
- Key features include an Internationalization Hub, Events calendar, CHED memo repository, integrated academic access, and official announcements published first on the site.
- Security and sustainability measures cover institutional-email-only access, two-factor authentication, restricted editing, content review and approval workflow, turnover manuals, and annual role continuity training.

See PLATFORM DEFENSE.pdf in the project root for full details.
